# 数据、标定与验证

此目录保存本地原始录制、背景、标签、设备标定和部署包。Git 仅跟踪本说明。请按会话保存文件和校验值，保留原始录制。

| 数据 | 用途 |
| --- | --- |
| S3 `live_w5500_timing.jsonl` | 在浏览器回放串口跟踪结果 |
| 原始 `.birdraw`、S3 UART 日志、计时映射 | 将原始点云与 S3 结果按帧关联 |
| 相机视频和接收时间元数据 | 对齐画面，辅助人工确认场景 |
| `s3_rk3588_release_20261121_01.zip` | 保存 2026-11-21 部署的固件、设备标定和回滚备份 |

每个会话记录采集条件、设备及时间域、真实鸟或模型、摆位、帧范围、标签依据和同步误差。缺失信息使用 `UNKNOWN`。场景标签只能说明某个时段的场景条件，逐帧目标身份和点集归属需要独立证据。

先按会话、摆位和物理个体分组，再划分开发、验证和测试。相邻帧和同一摆位的配对录制留在同一组。已用于调参和错误分析的会话属于开发数据。真实鸟识别及适用距离尚未独立验证。

历史采集及实验索引的本地备份为 `README_archive_20261122.md`。
