# RK3588-Lidar-IFW192S-Bird

**基于 IFW192S 激光雷达、面向 RK3588 部署的鸟类抗干扰感知研究。**

研究在稀疏点云和复杂背景中提取目标候选，区分鸟模型与相似干扰，并通过实测关联和时序确认输出可追溯的目标事件。开发顺序为 PC 离线验证、冻结算法与独立评估，再进行 RK3588 部署和性能测试。

> 当前公开版本仅包含项目说明与目录骨架，尚不提供可运行代码、模型权重或数据集。本地已有采集、回放、实例跟踪和离线分析工具；这些工具的存在不代表鸟类识别已经通过验证。

## 项目目标

- 保留 IFW192S 点云的原生网格、源行和时间信息，建立可复现的采集与回放流程。
- 在背景与支撑物、晃动物体等干扰中提取候选，并研究几何、强度与距离图特征的判别能力。
- 关联连续实测候选，处理遮挡、缺测及目标进入/撤出，输出具有证据来源的事件。
- 在独立摆位上评估误报与目标保留能力，随后验证 RK3588 的计算开销和长期运行表现。

识别输入规划为 LiDAR 数据。相机仅用于离线场景复核和标注参考；按接收时间关联不等于硬件同步，也不等于完成空间标定。

## 核心算法规划

以下为研究路线，具体方法须经过对照实验后确定。已有实验模块与拟采用的最终方案应分别记录。

```text
IFW192S 原始数据
    ↓
解码与输入质量检查
    ↓
背景证据与候选提取
    ↓
候选几何 / 强度 / 原生距离图特征
    ↓
目标与干扰分类（允许 UNKNOWN）
    ↓
当前实测关联与因果时序确认
    ↓
目标状态、实测点集及事件输出
    ↓
分组回放评估 → 冻结独立测试 → RK3588 性能验证
```

| 环节 | 规划方法 | 需要解决的问题 |
| --- | --- | --- |
| 数据解码与质量检查 | 保留设备时间戳、接收时间、原生格及源行；检查缺帧、异常值和有效覆盖 | 防止坏输入被解释为目标离开或背景变化 |
| 背景建模 | 研究无目标配对背景、距离稳定性与局部背景可用性 | 区分目标回波、背景和背景失效；不能简单过滤全部静止目标 |
| 候选提取 | 研究距离差分、原生网格连通性和 3D 密度聚类；显式记录工作区 | 减少目标与邻近背景、支撑物粘连；限定区域结果只代表该区域 |
| 特征与分类 | 以点数、空间尺寸、形状、强度统计和距离图特征建立可解释基线；轻量学习方法作为对照 | 避免记住固定摆位；缺少背景或超出已知分布时保留 UNKNOWN |
| 实测关联 | 对比空间门控、点集对应和线性分配；卡尔曼预测仅辅助搜索与关联 | 处理碎裂、合并、缺测与 ID 变化；预测不能生成当前实测点 |
| 时序确认 | 仅使用当前及历史实测，明确确认、暂失、退出和超时规则 | 平衡误报、事件碎裂与延迟；运动特征需先验证候选连续性 |
| 事件评估 | 固定工作区、配置和数据分组，统计误报事件、持续时间、UNKNOWN 覆盖 | 有逐事件真值后再计算召回及进入/退出延迟 |
| 板端部署 | 先测量完整链路，再选择是否向量化、压缩模型或使用硬件加速 | 记录延迟分布、吞吐、内存、丢帧与长时间稳定性 |

当前本地实例跟踪原型采用参考表面引导的 DBSCAN、3D 卡尔曼预测及门控线性分配。它依赖现场参考初始化，承担实例分割与关联；通用鸟类语义分类仍需单独验证。

静止候选分类为主要研究方向。运动分支先检查实测关联和可用窗口，再研究短时位移、路径及点数变化；不能用人工移动模型证明真实鸟行为，也不能预设“移动就是鸟”。

## 分阶段推进

1. **数据与真值整理**：保持原始录制不变，核对时间、背景和候选来源；区分场景标签、点集确认与事件标注。
2. **可复现基线**：先解决已确认鸟体候选被拒绝、背景证据不足和关联中断，固定几何/强度/距离图对照口径。
3. **抗干扰与时序评估**：加入无目标和相似干扰对照；同时检查误报、目标保留和事件碎裂，避免只优化单一指标。
4. **独立验证**：按物理摆位及采集组划分开发与测试，冻结方法后再使用保留测试组。
5. **RK3588 部署**：完成输入适配与性能测试；真实鸟实验另行建立证据，不从鸟模型结果直接外推。

## 数据与评估原则

- 同一录制的相邻帧及同一摆位的有/无目标配对不得随机拆入训练与测试；背景、参考与预处理参数也应遵守分组边界。
- 开发阶段反复查看的数据不再作为盲测证据。未经确认的候选、类别与状态保留 `UNKNOWN`。
- 场景中有鸟模型不代表每个候选都是鸟；场景标签不能直接转换成逐帧或逐点真值。
- 当前实测点与预测状态分别输出；缺测时不能沿用旧点、旧框冒充新测量。
- 评估记录输入与配置版本、数据分组及工作区。候选帧保留比例不能直接称为目标召回率。
- 读取传感器沿用共享只读连接；录制复用连接，不隐式启动或修改板端服务。

## 当前验证边界

项目处于鸟模型与干扰区分的探索阶段。既有固定场景跟踪、同场景回放及软件测试，不能证明新场景识别能力。离线分类与时序方案仍存在目标拒绝、干扰误报和候选连续性问题。

本仓库暂不宣称真实鸟识别准确率、独立事件召回率、精确离开延迟或 RK3588 实时性能。后续仅在对应证据成立后公布指标和适用条件。
